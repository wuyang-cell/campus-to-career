# M2 · 基础岗位通用能力

> 解决什么：大学期间该学什么技能，学到什么程度算学会。
> 核心原则：**一主一辅，不同时学两项以上。** 同时学四项的结果是四项都停在"打开过"。

---

## 〇、这个模块的定位（先读，否则会用错）

**这五项不是准入门槛，是基础岗位的通用工具。**

数据分析/Excel、剪辑、PS、AI 工作流、自媒体，对应的是大量入门岗位每天都在用的东西。学它们的目的是三个：

1. **够得着基础岗位**——运营、助理、市场、行政这类岗位，JD 里高频出现这些工具
2. **多一条出路**——本专业岗位少时，可迁移的技能就是第二个入口
3. **降低对单一方向的依赖**——一项技能换一个行业还能用

**明确反对一种误读**：不是"学完才敢投"。

| 误读 | 实际做法 |
|---|---|
| 先把五项学完，再开始投简历 | 学一项能讲清的就投，投递与学习**并行** |
| 技能不齐备就没资格投 | 简历上有一项能扛住追问的产出，就够投了 |
| 学得越多越安全 | 同时学超过两项，四项都会停在"打开过" |

**技能与投递是并行关系，不是前后置关系。** 这是本模块与 M3/M4 的分工：M3 定投什么，M4 决定怎么被看见，M2 提供可以被写进简历的素材——三者可以同时进行。

**大一大二没有目标岗位可倒推时，本模块是唯一入口。** 大三之后主技能改由 JD 倒推，本模块退为"按需补"。

---

## 一、选择原则

| 规则 | 说明 |
|---|---|
| **一主一辅** | 主技能持续推进，辅技能保持接触。不同时开两项主技能 |
| **主技能由岗位决定（大三及以后）** | 有目标岗位时，按 JD 高频要求选；没有时按 M3 的候选方向选 |
| **先有产出，再谈精通** | 做不出一个能展示的东西，说明范围定大了 |
| **技能不等于证书** | 证书是门槛，作品才是证据 |
| **鼓励尝试，不设门槛** | 大一可以只"接触"，不要求产出（见 M1） |

### 1.1 大一无方向时，按「跨行业可迁移性」挑第一项

**大一的困境是：没有目标岗位，按什么选技能？**

不要按"哪个热门"选，按"**换任何方向都用得上**"选。

| 技能 | 跨行业可迁移性 | 只对哪些方向有用 |
|---|---|---|
| **数据分析 / Excel** | **最高** | 几乎全部（运营、财务、HR、销售、行政、研究） |
| **AI 工作流** | 高 | 全部白领岗，但门槛在"能不能拆任务"，不在工具 |
| 剪辑 | 中 | 内容、电商、教培 |
| PS / 设计 | 中 | 设计、电商、新媒体 |
| 自媒体 | 中 | 内容、运营；且需要长期投入才有产出 |

**选择顺序：先看兴趣，再看可迁移性。**

| 序 | 先问什么 | 怎么选 |
|---|---|---|
| 1 | **你对什么有兴趣？** | 有兴趣 → 按兴趣选。**兴趣是唯一能撑过"学不动"那段的理由** |
| 2 | 说不清 / 都行 | 按上面的可迁移性排序，默认 **数据分析 / Excel** |

**为什么兴趣优先**：技能学到能用的程度，中间有一段很枯燥。没兴趣的人会停在这段，学一半比不学更浪费。**可迁移性解决"选错了怎么办"，兴趣解决"能不能坚持"。**

**为什么没兴趣时选数据分析 / Excel**：它**最不会白学**——换什么方向都能带走。

**大二有了目标岗位后，改按 JD 选主技能，不必从一而终。**

## 二、数据分析 / Excel

**对口岗位**：数据运营、运营助理、电商运营、市场专员、财务分析、行政分析

| 项 | 内容 |
|---|---|
| **最小产出** | 一份 2 页分析报告：问题 → 数据 → 结论 → 建议，用真实数据 |
| **工具** | Excel（透视表、VLOOKUP/XLOOKUP、条件格式）→ SQL（SELECT/JOIN/GROUP BY）→ BI（可选） |
| **推进顺序** | 第一步 Excel 核心函数 → 第二步 SQL 基础 → 第三步 完成一份完整报告 |
| **验收问题** | 这个结论怎么来的？样本多少？口径是什么？和谁比？ |
| **常见坑** | 只学函数不做完整报告；用玩具数据；结论没有建议 |

**"真实数据"从哪来**：公开数据集、自己抓的公开数据、实习中的脱敏数据、学校课程数据。不要用"泰坦尼克"这类练手集当项目。

---

## 三、剪辑

**对口岗位**：剪辑师、短视频运营、内容运营、电商视频、活动执行

| 项 | 内容 |
|---|---|
| **最小产出** | 3 条成片：15 秒（卡点）、60 秒（叙事）、3 分钟（完整结构），风格各不同 |
| **工具** | 剪映专业版（入门）→ Premiere（进阶）；音频用 Audition 或剪映自带 |
| **推进顺序** | 第一步 工具与导出 → 第二步 拆解并复刻 3 条对标视频 → 第三步 原创 1 条 + 整理作品集 |
| **验收问题** | 为什么这么剪？节奏怎么定？素材为什么选这段？ |
| **常见坑** | 只做混剪没有原创结构；不会按平台导出（比例/码率/封面）；作品集只有成片没有思路 |

**作品集规格**：3–5 条，每条附 1 段"我的思路"（30 字）。没有思路的成片，面试官无法判断是不是你做的。

---

## 四、PS / 设计基础

**对口岗位**：电商美工、新媒体运营、品牌助理、活动策划

| 项 | 内容 |
|---|---|
| **最小产出** | 3 张海报 + 1 套封面（同主题 3 张，体现一致性） |
| **工具** | Photoshop（抠图/合成/排版）→ Canva/稿定（快速出图） |
| **推进顺序** | 第一步 工具 → 第二步 临摹 3 张 → 第三步 同一主题原创 3 张 |
| **验收问题** | 为什么用这个配色？信息层级怎么排？主视觉想让人看什么？ |
| **常见坑** | 只学工具不学版式；临摹作品当原创；不考虑投放场景（尺寸/平台） |

---

## 五、AI 深度使用

**对口岗位**：几乎所有白领岗，尤其是运营、市场、行政、研究助理

**注意**：这一项最容易注水。"会用 ChatGPT"不是技能，"能搭一个可复用工作流"才是。

| 项 | 内容 |
|---|---|
| **最小产出** | 一个**可复用工作流**：把一个真实任务拆成 4–6 步，标明哪几步交给 AI、哪几步必须人工校验，并记录节省的时间 |
| **示例** | 资料检索 → 提纲 → 初稿 → 事实核对 → 改写 → 定稿；每步写明输入、输出、校验方式 |
| **推进顺序** | 第一步 熟悉 2–3 个工具 → 第二步 把一个真实任务拆解并跑通 → 第三步 固化成模板/SOP，再跑第二个任务 |
| **验收问题** | 哪些环节不能交给 AI？你怎么校验输出？错了怎么发现？ |
| **常见坑** | 把"生成过"当"会用"；不校验事实；不会写结构化提示；把 AI 输出直接交付 |

**必须会的一件事**：识别 AI 的幻觉。凡涉及数字、人名、法规、引用，一律回原始来源核对。

## 六、自媒体账号

**对口岗位**：内容运营、新媒体、剪辑、个人品牌；对非对口岗位也有"可展示作品"的价值

| 项 | 内容 |
|---|---|
| **最小产出** | 累计 ≥ 8 条更新（同一主题）+ 1 份数据复盘（播放、涨粉、完播、互动） |
| **平台选择** | 与目标岗位一致：图文→小红书；短视频→抖音/视频号；长文→公众号 |
| **推进顺序** | 第一步 定选题与人设 → 第二步 稳定更新到 ≥ 8 条 → 第三步 复盘 → 第四步 按复盘调整再更 3 条 |
| **验收问题** | 哪条数据最好？为什么？下一条怎么改？ |
| **常见坑** | 追爆款、断更、只发不复盘、把账号做成"生活记录"没有主题 |

**目的不是当网红**，是拿到三样东西：作品、数据、可讲的判断。

---

## 七、推进顺序（通用模板）

**只给顺序，不给周期。** 每一步的出口是产出，不是日期；做不出来就停在原地。

| 步 | 目标 | 产出 |
|---|---|---|
| 1 | 工具入门 | 做出第一个"丑但完整"的东西 |
| 2 | 临摹对标 | 3 个样例，附拆解笔记 |
| 3 | 真实任务 | 1 个原创，用真实数据/需求 |
| 4 | 整理作品集 | 3–5 件作品 + 每件 30 字思路 + 能讲 3 分钟 |

---

## 八、输出：一项技能，一条推进线

```
【主技能】__（选它的理由：对应岗位 __，JD 出现频次 __）
【辅技能】__（或写"暂不开辅技能"）
【最小产出】__（做出这个就算入门）
【现在推进到第几步】__
【验收问题】__（能当场答出来，才算学会）
```

**不要给学习计划表。** 只给产出标准与当前进度，时间由用户自己排——在校生的时间是碎的，排出来的周计划第一周就会崩。

## 九、判停

> 学几项、学多久，是他的选择。这里只给"这个信号说明什么"。

| 信号 | 说明什么 | 通常有效（不是必须） |
|---|---|---|
| 同时学 > 2 项 | 三项都到不了可展示水平 | 收窄到 1 主 1 辅；也可以不砍项，把每项的完成标准降一档 |
| 一直没有可展示产出 | 范围铺太宽，或"完成"定得太高 | 砍半范围，或把"完成"重新定义为"能演示一次" |
| 学完讲不出"为什么这么做" | 只有步骤记忆，没有判断依据 | 不算学会；要补的是判断依据，不是再练一遍 |
| 技能与目标岗位无关 | 学的东西用不上 | 先回方向确认岗位，再决定学什么 |
| 大一 | 时间还长，接触比产出重要 | 只要求"接触过"，不要求作品 |
