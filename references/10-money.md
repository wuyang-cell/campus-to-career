# M10 · 理财（现金流与储蓄）

> 解决什么：不同阶段怎么管钱。
> **边界：只讲现金流、储蓄、预算、五险一金常识。不推荐任何理财产品，不做投资建议。**

> 说明：本模块为初版框架，用户后续会补充资料，届时以补充内容为准。

---

## 〇、第一条规则：不借钱消费

**如果整个理财模块只能留一句给大一学生，留这句：**

> **不要借钱消费——不碰校园贷、不开分期买数码、不为任何消费品贷款。**

**为什么是这条，不是"记账"**：

| | 记账 | 不负债 |
|---|---|---|
| 性质 | 优化项 | **保命项** |
| 收益 | 每月少花 10% | 避免一笔能毁掉 2 年现金流的债 |
| 代价 | 不做也不会出事 | 不做可能滚到本金的 3 倍，且上报征信 |

一个月花 1500 全花光，最坏结果是吃泡面；借 1500 利滚利，半年后可能变成 5000，还会影响后续房贷、租房审核和部分岗位背调。

**这对大一大二尤其重要**：这个阶段收入最低、判断力最弱、对"分期"最没有抵抗力。

**关于征信的精确表述**：《征信业管理条例》第 16 条——不良信息自**不良行为或者事件终止之日**起保存 5 年。即**结清之日起 5 年**，不是逾期发生之日起。

## 〇.1 先看清账：月薪 5–8k 阶段，谈"分配比例"是伪命题

`[通用·2026]` 一线城市合租的真实月度账：

```
房租（合租单间）        1500
吃饭（自己做 + 外卖）    1200
通勤                    300
水电、话费、日用         300
─────────────────────────
固定支出合计            3300

月薪 5000 → 剩 1700
扣掉社交与意外           能存 500–1000
```

**在这个账上，讨论"20% 储蓄还是 30% 储蓄"没有意义——分母太小。**

**三套流行分法，全部是内容产品，不是实操方法：**

| 说法 | 真实来源 |
|---|---|
| 50/30/20 | Elizabeth Warren 给**美国家庭**的建议，不是给中国月薪 5k 应届生的 |
| 532 | 内容创作者改编 |
| 另一版 50/30/20 | 同上 |

**所以这个阶段只讲三件事，按顺序：**

| 序 | 事 | 为什么排这个顺序 |
|---|---|---|
| 1 | **不负债** | 保命项。一笔消费贷能吃掉两年现金流（见第〇节） |
| 2 | **攒 3 个月应急金** | 哪怕只有 5000 块。它不是理财，是"失业时不至于立刻崩"的缓冲 |
| 3 | **剩下的精力全部投到提高收入** | 月薪从 5k 到 8k，比"把 500 块分配得更科学"重要 10 倍 |

**"理财"在这个阶段只有两条：不要借钱、不要碰投资。** 分配比例是月薪过万、固定支出稳定之后才需要考虑的事。

**如果连 500–1000 都存不下**，那不是分配问题，是收入问题——回去看 M3 和 M6，不是研究记账 App。

## 一、四个阶段

| 阶段 | 主线 | 关键动作 | 完成标准 |
|---|---|---|---|
| **大一 / 大二** | 建立记账习惯 | 记 3 个月流水；分清"需要/想要" | 能说出每月钱花在哪三类 |
| **大三** | 从"花父母的钱"到"自己挣一部分" | 实习收入先存后花；攒第一笔应急金 | 有 ≥ 1 个月生活费的存款 |
| **大四** | 为求职付成本 | 做求职预算；准备异地求职金 | 有一笔专用求职资金 |
| **入职后** | 从"有收入"到"有结余" | 五险一金核对；强制储蓄；应急金 3–6 个月 | 每月结余 ≥ 目标储蓄额 |

## 二、四个核心概念

### 2.1 先存后花

```
错误顺序：收入 − 支出 = 储蓄（通常剩不下）
正确顺序：收入 − 储蓄 = 可花（储蓄先扣走）
```

**不要用"储蓄率"开头，用固定金额。**

储蓄率是结果，不是目标：月薪 5000 的 10% 是 500，月薪 20000 的 10% 是 2000，同样比例，安全感完全不同。

| 阶段 | 固定金额 |
|---|---|
| 在校 | 200–500 元/月 |
| 实习 / 刚入职 | 500–1500 元/月 |
| 收入稳定后 | 每年上调一次，按"上一年多存了多少"定 |

**关键是"固定"和"自动"，不是"比例正确"。**

**「先存后花」必须是自动的，靠意志力一定失败。** 行为上有个规律：需要主动决定"要不要存"时，人会选即时消费；把储蓄设成默认动作，就能绕过这个决策。

| 做法 | 具体操作 |
|---|---|
| 发薪日自动转出 | 银行 App 设定期转账，发薪当天把储蓄部分转到独立账户 |
| 用两张卡 | 一张只进不出（储蓄），一张日常消费。不要用同一张卡"看着余额花" |
| 额度从低开始 | 10% 存不下来就先 5%，关键是养成"每月少了这笔钱"的体感 |

**市面上的分配比例全部不要用。** 50/30/20 出自 Elizabeth Warren 给美国家庭的建议，532 是内容创作者的改编——**三套都是内容产品，不是实操方法**（详见 〇.1）。

**正确做法是反过来算**：先扣掉房租、通勤这些动不了的固定支出，再定一个"发薪日自动转出"的固定储蓄金额，剩下的才是可花的。顺序是"固定支出 → 固定储蓄 → 剩下的随便花"，不是"收入 × 百分比"。

### 2.2 需要 vs 想要

| 需要 | 想要 |
|---|---|
| 房租、吃饭、通勤、通讯、必要医疗 | 外卖升级、新手机、会员、潮玩、频繁聚餐 |

**判断法**：这笔钱不花，会影响你下周的正常生活吗？不影响 = 想要。

### 2.3 应急金

```
应急金 = 3–6 个月的全部支出
```

| 阶段 | 目标 |
|---|---|
| 在校 | 1 个月生活费（应对突发，不向家里开口） |
| 求职期 | 2–3 个月（异地求职的底线） |
| 入职后 | 3–6 个月（应对失业、生病、换城市） |

**按行业调整**（`[通用]`）：标准 3–6 个月是平均值，收入越不稳定、裁员越集中，要留得越多。

| 情况 | 建议 |
|---|---|
| 体制内、医疗、教育 | 3 个月够 |
| 一般企业 | 3–6 个月 |
| 互联网、教培、外贸、地产等波动大的行业 | **9–12 个月** |
| 家里有负债或需要你补贴 | 再加 3 个月 |

**现金要分三层，不要混成一笔**（`[通用]`）：

| 层 | 额度 | 放哪 | 用途 |
|---|---|---|---|
| 第一层 零花 | 1 个月支出 | 活期 / 余额类 | 日常吃饭通勤，随用随取 |
| 第二层 应急 | 2–5 个月支出 | 货币基金 / T+0 理财 | 失业、生病、突然要搬家 |
| 第三层 短期目标 | 按目标定 | 3 个月–1 年定期 / 短债 | 押一付三、换城市、考证 |

**放在哪**：应急金不追求收益，追求"随时能拿到"。为多 1% 的收益把应急金锁三个月，等于没有应急金。

### 2.4 固定支出 vs 可变支出

| 类型 | 例子 | 能不能砍 |
|---|---|---|
| 固定 | 房租、话费套餐、会员订阅 | 签约时就该压低，签完难改 |
| 可变 | 吃饭、交通、娱乐 | 每月可调 |

**结论**：省钱要从**固定支出**下手（房租、套餐），不要从吃饭下手——吃饭省下来的钱少，且伤身体。

## 三、与求职直接相关的四笔钱

| 用途 | 金额 | 什么时候要 | 出处 |
|---|---|---|---|
| **异地实习准备金** | 1–2 个月生活费，约 5,000–10,000 元 | 决定去外地实习前 | M1 / M6 |
| **异地求职金** | 2–3 个月全部开支 | 决定去外地找工作前 | M8 动身前清单 |
| **首次入住现金** | 押一付一 ≈ 2.5 个月租金；押一付三 ≈ 4.5 个月 | 签租房合同前 | M8 |
| **求职成本** | 简历打印、交通、正装、证件照、体检 | 大四秋招前 | M6 |

**判断规则**：这四笔钱没备齐，就不要做对应的动作。不是"到了再说"。

## 四、五险一金：只需要知道三件事

| 险种 | 谁交 | 你能感知到什么 |
|---|---|---|
| 养老 | 单位 + 个人 | 换城市/换工作时需转移 |
| 医疗 | 单位 + 个人 | 看病报销，断缴影响待遇 |
| 失业 | 单位 + 个人 | 缴满一定年限失业可领 |
| 工伤 | 单位 | 工作期间受伤 |
| 生育 | 单位 | 生育相关费用 |
| 公积金 | 单位 + 个人 | 租房/买房可提取 |

**只需要核对三件事**：

1. **有没有缴**（入职当月就该登记）`[待核·社会保险法]`
2. **按什么基数缴**（按最低工资 vs 按实际工资，差距很大）
3. **什么时候开始缴**（入职当月 / 次月）

**公积金**：即使不买房，租房也可提取。问 HR 提取流程。

## 四点五、刚工作时最容易做错的三件事

`[通用]`

| 错法 | 后果 | 正确做法 |
|---|---|---|
| **把第一份工资当"可花额度"** | 头三个月把钱花在换手机、租好房、请客上，之后每个月都在补窟窿 | 第一个月就按"收入 − 储蓄 = 可花"起手，哪怕只存 5% |
| **为了省钱租到远郊** | 每天多 2 小时通勤，一年 500 小时。这些时间本该用来学东西或接活 | 通勤控制在单程 60 分钟内，多付的房租是买时间 |
| **用分期/白条买"职场装备"** | 负债一开始就背上，之后每个月的现金流都被锁死 | 需要的东西攒钱买，不需要的等一个月再决定 |

## 五、绝对不碰的四类

| 类型 | 为什么 |
|---|---|
| 校园贷 / 消费贷 | 利率高，且容易滚成债务 |
| 租金贷 / 分期付房租 | 本质是贷款，退租仍要还 |
| 培训贷（"先学后付"） | 承诺包就业的多为套路 |
| 任何"高收益、保本"的产品 | 保本与高收益不可兼得 |

## 七、判停

| 条件 | 动作 |
|---|---|
| 用户问"买什么基金/股票" | 明确不提供，只讲现金流 |
| 用户没有稳定收入 | 只做记账与消费分类，不谈储蓄率 |
| 用户存款为负（有负债） | 先列债务清单与利率，优先还高息 |
| 用户想"靠理财覆盖生活费" | 直接说明不现实，回到收入端 |
| 用户是艺术/自由职业方向 | 增加"收入不稳定期"的现金流规划：按 6 个月备 |
