# M9 · 入职、劳动合同与试用期

> 解决什么：实习期做什么、劳动合同看什么、试用期怎么过。
> 核心原则：**转正不是最后一个月准备的。试用期从第一天就当成项目做，全程留证据。**

---

## 一、先分清两个"期"

| | 实习期 | 试用期 |
|---|---|---|
| 身份 | 在校生 | 已建立劳动关系 |
| 签什么 | 实习协议（不是劳动合同） | 包含在劳动合同内 |
| 有社保吗 | 通常没有（各地不同）`[待核]` | 应当缴纳 `[待核·社会保险法]` |
| 适用本模块 | 第二节 | 第三、四节 |

**别把实习协议当劳动合同签。** 实习协议不建立劳动关系，出了纠纷适用的是民法不是劳动法。

---

## 二、实习期该做什么

`[通用]` 本节后半部分的动作来自公开职场建议的共性总结，是通行判断，不是统计结论。

### 入职前 5 天（多数人跳过，性价比最高）

| # | 动作 | 为什么 |
|---|---|---|
| 1 | **联系带教，约 10 分钟**：问第一天几点到、带什么、找谁 | 留下"主动"的第一印象；带教通常欢迎你提前问 |
| 2 | 看部门 wiki / 官网 / 近期项目新闻 | 第一天就能跟上同事聊天，不一脸茫然 |
| 3 | 确认通勤路线与着装要求 | 第一天迟到或穿错，抵消后面两周的努力 |
| 4 | 提前 1–2 天调作息 | 实习第一天精神饱满，比什么都重要 |

### 第 1 周

| # | 动作 | 产出 |
|---|---|---|
| 1 | **拿到书面确认**：谁带你、你负责哪块、交付标准与时间点 | 半页纸发给 leader 请其确认——第一周就把"我以为"变成"我们说好的" |
| 2 | **打通信息通道**：加齐相关同事、进所有工作群、问清"要数据找谁 / 要权限找谁 / 审批走谁" | 一张联系人与流程清单。这一步决定后面三个月的效率 |
| 3 | **做完并交付一件小事**，小到当天能完成 | 你在团队里的第一个"可被记住的交付物" |
| 4 | **问清转正考核看什么**：哪几个指标、什么时间点评估、上一届留了几个 | 不问清，可能做满三个月才发现方向不对 |

**第一周不要提流程改进建议。** 这是最常见的减分项——你还不了解约束，提的建议多半是团队早就试过的。

**提问用"选择题"，不用"问答题"**：

```
❌ "这个报表怎么做？"
✅ "这个报表我可以用 A 方法或 B 方法做，您觉得哪个更合适？"
```

差别在于：前者把思考成本转给对方，后者说明你已经想过。带教愿不愿意带你，很大程度取决于这个细节。

### 前 1 个月

| 动作 | 产出 |
|---|---|
| 把一件事做完整（不是只做片段） | 1 个可描述的完整任务 |
| 主动要反馈 | 领导眼里你哪里行、哪里不行 |
| 记录可量化结果 | 哪怕很小（处理了多少单、缩短了多少时间） |

**转正实际看三个指标**（`[通用]`）：

| 指标 | 标准 | 怎么自证 |
|---|---|---|
| **任务完成率** | 分配的任务能否按时按质完成，通常 ≥90% | 工作台账：日期 / 任务 / 结果 / 证据 |
| **工作质量** | 交付物是否符合要求、返工少 | 保留返工记录与修改前后对比 |
| **主动性** | 是否主动问、做完是否主动找事 | 主动承担的任务清单 |

三个都达标，转正基本稳。某一项不达标，早问早改，别拖到最后。

### 第 6–8 周：主动约一次 1v1

**不要等实习快结束才问转正。** 中期主动约直属领导 15 分钟，说三件事：

1. 阶段性成果（用 STAR：什么场景、你负责什么、怎么做的、什么结果）
2. 我想留下来，想了解转正标准和现在的差距
3. 哪些地方我可以马上改进

**这个动作的价值不是"表现积极"，是提前拿到信息**——如果对方明确说没有 HC，你可以把剩下的一半时间用来找下家。

### 全程

```
每段实习结束当天，简历上就该多一句带结果的描述。
不要留到秋招再回忆。
```

**为什么**：三个月后你只会记得"做过运营"，记不得具体数字。当天写，才有细节。

### 转正的真实逻辑：有没有人替你背书

`[通用]` **转正不是看 KPI 完成率，是看有没有人愿意为你说话。**

| 事实 | 含义 |
|---|---|
| 招你进来已经花了成本 | 只要你不出大问题，通常不会轻易刷掉 |
| 带教离职/转岗 → 没人替你说话 | KPI 再好也悬 |
| **一个 HC 招两个实习生 PK** | 你是被比较下去的那个，做对所有事也没用 |

**该问的一句**（面试或入职时）："这个岗位的转正名额有几个？现在有几个实习生在竞争？"——问不出口，就可能白干三个月。

### 什么时候表态是减分

| 场景 | 为什么减分 |
|---|---|
| 表现一般就急着表态 | 显得对自己定位不清，反而提醒领导"这人没数" |
| 在部门周会等**公开场合**表态 | 给领导压力——他还没决定，你就公开要 offer |
| 离评估还有两个月就催 | 对方无法回答，只会觉得你急 |

**加分时机**：转正评估前 **2 周**，**私下**问带教："我这个表现，转正希望大吗？还差什么？"——这是请教，不是索要。

### 态度 vs 产出：哪个更容易被刷

`[通用]` 与公开说法不一致：

| 岗位类型 | 更容易留下来的是 |
|---|---|
| **技术岗**（研发、测试、数据） | **产出好但不合群**。团队缺的是能干活的人，不是老好人 |
| **运营、产品、HR** | **合群更重要**。这类岗日常就是跨部门协作，不合群是硬伤 |

公开建议都说"态度最重要"，是因为面对的是大多数人（产出都一般），所以强调态度。**但如果你产出明显高于同批实习生，不必为了合群牺牲产出。**

### 结束前：主动争取，不要等

| 动作 | 说明 |
|---|---|
| **按上面的时机表态** | 不是"必须说"，是"在评估前 2 周私下说" |
| 提交转正申请 | 按公司流程走，不要只靠口头 |
| 整理成果总结 | 一页纸：做了什么、结果、学到什么。这是转正答辩和下一次面试的共同素材 |
| 要一封推荐语/背调承诺 | 即使不留用，也带走这个 |

**不要以为"表现好就会自动转正"。** 但也不要以为"表态越早越好"——时机不对，表态是减分。

### 判停

| 条件 | 动作 |
|---|---|
| 实习只做打杂，1 个月没有任何完整任务 | 主动要任务；要不到，考虑换 |
| 问了转正名额，明确说没有 | **不要立刻走**。留到结束拿一段完整经历（< 3 个月的实习写简历上没分量），但换策略：主动要一个能写进简历的成果 + 同时投下一份 |
| 领导从不给反馈 | 主动约一次 15 分钟，问"我哪里需要改" |
| 实习结束写不出一句带结果的话 | 说明过程没记录，不是没成果 |

### 几个高频场景怎么选

**通用建议在这里没用，因为没有标准答案。下面给决策规则，不是给结论。** `[通用]`

| 场景 | 决策规则 |
|---|---|
| 带教让你做一件明显没价值的事 | **做，但加一步**：做完后问"这件事的用途是什么？我想下次做得更到位"——先判断是真没价值，还是你没看懂 |
| 领导在会上当众批评你 | **当场只认事实，不辩解**："这块我确实没做好，会后我确认一下再改。" 争论留到私下 |
| 两个 offer 差 1k，一个 965 一个 996 | 算时薪：996 一年约多干 700 小时。差 1k × 12 = 1.2 万，÷700 ≈ **17 元/小时**。低于你的加班心理价位就选 965 |
| 实习一半发现这个岗位没 HC | 见"判停"表最后一行：不走，但换策略 |
| 带教从不给反馈 | 不要问"我做得怎么样"（他会说"挺好的"），改问"如果让我把这件事再做一遍，你会让我改哪一处" |

## 三、劳动合同：签字前核对 10 项

| # | 核对项 | 要看什么 | 不合格 |
|---|---|---|---|
| 1 | 主体 | 公司名称与面试公司一致；有公章 | 不一致不签 |
| 2 | 期限 | 固定期限 / 无固定期限 / 以完成一定工作为期限 | 空白不签 |
| 3 | 试用期 | 时长与合同期限匹配；同一单位只能约定一次 | 超法定上限不签 |
| 4 | 工作内容与地点 | 岗位名称、工作地点写明 | 只写"服从安排"要问清 |
| 5 | 工时制度 | 标准 / 综合计算 / 不定时 | 后两者影响加班费 |
| 6 | 薪酬结构 | 无责底薪、绩效、补贴、发放日 | 只写"综合工资"要拆分 |
| 7 | 社保公积金 | 缴纳基数、起缴月份 | 不缴不签 `[待核]` |
| 8 | 竞业与保密 | 是否限制、有无补偿 | 无补偿的竞业要问清 |
| 9 | 违约条款 | 服务期、培训费、违约金 | 不合法条款要提出 |
| 10 | 份数与签字 | 一式两份、双方签字盖章、自留原件 | 只签一份不签 |

### 五个最容易踩的坑

| # | 坑 | 后果 | 依据 |
|---|---|---|---|
| 1 | **试用期与合同期不匹配** | 超期部分无效，但你会白干一段 | 《劳动合同法》第 19 条：3 个月–1 年 → ≤1 个月；1–3 年 → ≤2 个月；3 年以上/无固定 → ≤6 个月；同一单位只能约定一次；仅约定试用期的，试用期不成立 |
| 2 | **试用期工资打折过头** | 少拿的钱很难追回 | 《劳动合同法实施条例》第 15 条：不低于本单位同岗最低档工资或合同约定工资的 **80%**，且不低于当地最低工资 |
| 3 | **"自愿放弃社保"或"社保折现发工资"** | 医疗、养老、落户全受影响 | 法释〔2025〕12 号第 19 条：该约定或承诺**无效**；单位未依法缴社保，劳动者可依第 38 条第 3 项解除并要经济补偿 |
| 4 | **全员签竞业限制却不给补偿** | 离职后被限制择业 | 第 23 条要求按月给补偿；法释〔2025〕12 号第 13 条：未接触商业秘密的可请求确认条款不生效；范围、地域、期限与所知秘密不匹配的，超出部分无效 |
| 5 | **约定违约金、培训费、押金** | 离职被索赔 | 第 25 条：除第 22 条（专项培训服务期）、第 23 条（竞业限制）外，不得约定由劳动者承担违约金；第 9 条：不得扣押证件、不得要求担保或收取财物 |

### 要求先签空白合同怎么办

**结论：不签。**

依据：《劳动合同法》第 16 条第 2 款（文本由用人单位和劳动者各执一份）+ 第 17 条（必备条款）+ 第 81 条（未载明必备条款，责令改正，造成损害应赔偿）。

**可执行动作**：

1. 要求发电子版预览，看完再签
2. 逐页签，不要只在末页签
3. 两份各持一份，拍照留存

**对方坚持"先签后补"时**：可要求出具盖章的《条款补正承诺书》写明补齐日期，但仍有风险。**宁可放弃这个 offer。** 若已签，保留聊天记录与合同照片，事后可主张第 26 条（欺诈致违背真实意思订立，合同无效）或第 81 条。

### 试用期的法定参考

| 合同期限 | 试用期上限 |
|---|---|
| 不满 3 个月 / 以完成一定工作任务为期限 | 不得约定试用期 |
| 3 个月以上不满 1 年 | ≤ 1 个月 |
| 1 年以上不满 3 年 | ≤ 2 个月 |
| 3 年以上固定期限 / 无固定期限 | ≤ 6 个月 |

**试用期工资**：不得低于本单位同岗位最低档工资或合同约定工资的 80%，且不低于当地最低工资。
`[规则·以现行《劳动合同法》为准，签约前核对条文]`

### 风险信号

分两类：**合同类**看纸面，**行为类**看它实际怎么做。行为类更早暴露问题。

**合同类**

| 信号 | 处理 |
|---|---|
| 试用期不缴社保 | 书面询问 HR，保留记录 |
| 试用期超过法定上限 | 要求书面说明 |
| 合同主体与面试公司不一致 | 问清是外包还是主体变更 |
| 要求先交培训费/押金/服装费 | 拒绝 |
| 要求签"自愿放弃社保" | 拒绝，保留证据（该约定无效，见法释〔2025〕12 号第 19 条） |

**行为类：九个"该走了"的观察信号**

只看行为，不看感受。出现三条以上，说明这份工作不值得留。

| # | 观察信号 | 怎么验证 |
|---|---|---|
| 1 | 入职满 1 个月仍未签劳动合同，或只让你签"实习协议/劳务协议" | 看自己手里有没有合同原件 |
| 2 | 社保公积金未开户或未缴 | 国家社保公共服务平台 / 当地社保 APP 自查 |
| 3 | 要求书面考核标准时，leader 反复回避或说"到时候再说" | 连问两次，看是否给书面 |
| 4 | 你提的问题永远得到"你自己悟"，且团队内无人可问 | 一周内试三次 |
| 5 | 可验证的人员流动：上一任半年内换过 2 人，或团队 3 个月离职 3 人以上 | 问 HR"这个岗位上一任做了多久" |
| 6 | 连续 3 周工时超 60 小时，且无加班审批、无调休记录 | 看考勤与工资条 |
| 7 | **发薪日第一次推迟** | 第一次推迟就是信号，不用等第二次 |
| 8 | 让你做与 JD 无关的私人事务，或要求"先垫钱再报销" | 记录次数与金额 |
| 9 | 面试承诺的岗位/城市/薪资，入职后单方变更 | 对比 offer 与合同 |

**争议处理**：本模块只做核对，不出法律意见。保留合同、聊天记录、工资流水，咨询当地人社部门、劳动监察或律师。

## 四、试用期：30 / 60 / 90 天

### 第 1 周：对齐目标（最关键，多数人跳过）

入职 3 天内，约直属领导 20 分钟，确认三件事：

| # | 问什么 | 话术 |
|---|---|---|
| 1 | 转正核心指标 | "试用期我最需要达成的 2–3 个指标是什么？" |
| 2 | 交付标准 | "周报要什么格式？复盘多久一次？哪些是我的职责边界？" |
| 3 | 验收时间 | "转正评审大概在第几个月？由谁评？" |

**留痕**：口头确认后发一条消息复述："我理解是 A/B/C 三项，对吗？"

### 前 30 天：三件事 + 三件硬核对

| # | 动作 | 产出 |
|---|---|---|
| 1 | **把考核标准落到纸面**：指标、评估人、评估时间点 | 一份写下来的标准。口头标准等于没有标准 |
| 2 | **找齐 3 个信息节点人**（直属 leader、HR、跨部门对接人），第 2 周各做一次 15 分钟 1v1 | 每人问一句"我这个岗位做好是什么样" |
| 3 | **建立工作台账**：每周五发一页周报（本周产出 / 卡点 / 下周计划） | 转正时这是你唯一能自证的证据 |

**并行核对三件硬事**：合同是否已签、社保是否已开户、工资卡与发薪日是否确认。

**为什么是这三件**：它们都发生在你还没做出成果的时候，但一旦漏掉，后面补不回来——尤其社保开户月份。

### 前 2 个月：做事情 + 留证据

**底线**：不要只做打杂和回复消息，必须至少做出 1 项可量化成果。

**周报四段**：

```
1. 本周做了什么（3–5 条，动词开头）
2. 数据变化（对比上周/上月，带数字）
3. 遇到的问题（1–2 个，附你的判断）
4. 下周计划（2–3 条，可验收）
```

**小项目（四选一，4–6 周内能看到变化）**：

| 类型 | 产出 |
|---|---|
| 用户/客户分层 | 分层前后转化对比 |
| 话术/SOP 优化 | 响应时长、解决率变化 |
| 流失复盘 | 流失原因分布 + 挽留率 |
| 报表自动化 | 节省工时/周 |

**关键**：做之前记录基线，做之后记录变化。没有前后对比，就不算成果。

### 转正前 1 个月：述职四模块

| 模块 | 内容 | 常见错误 |
|---|---|---|
| 目标回顾 | 入职时约定的 KPI，逐条对照 | 没有书面目标 |
| 工作成果 | 必须量化：新增/留存/转化/效率 | 只写"认真负责" |
| 问题与复盘 | 坦诚不足 + 原因 + 已做的改进 | 只报喜或只道歉 |
| 转正后规划 | 未来 3 个月目标与动作 | 写成空话 |

**没有大增长怎么办**：写流程优化（省了多少工时）、效率提升（几小时→几小时）、问题沉淀（几份文档）。这三类对应届生同样成立，且更容易讲出实据。

### 四类避坑

| 坑 | 后果 | 对策 |
|---|---|---|
| 只做客服式回复 | 被判定可替代性强 | 每月至少一次数据复盘 |
| 只埋头不汇报 | 领导不知道你做了什么 | 周报固定发 |
| 职责边界不清，无底线接活 | 本职 KPI 没完成 | 接活前问"这个优先级高于我的 KPI 吗" |
| 承诺做不到的高目标 | 期末对不上，信任崩塌 | 承诺打八折，交付超预期 |

```
【下一个节点】__（到期该做的那件事）
```

**不同阶段只说不同的事**：第 1 周给"拿到书面确认"，第 6–8 周给"约 1v1"，结束前给"表态"。**一次只给一个**，全给等于没给。

## 六、判停

| 条件 | 动作 |
|---|---|
| 第 1 周结束仍无书面 KPI | 主动约；仍无，自己写一份发领导确认 |
| 连续 2 个月无可量化成果 | 立刻启动一个小项目，哪怕很小 |
| 转正前 1 个月还没准备述职 | 本周内搭出四模块框架 |
| 领导频繁更换 | 目标与成果写成文档，每换一次同步一次 |
| 合同有任意一项核对不过 | 不签，先问清 |
| 出现欠薪/停缴社保 | 保留证据，咨询人社部门 |
