# M7 · 面试与模拟面试

> 解决什么：怎么答、怎么练。
> 本模块支持**模拟面试**：按岗位描述与简历出题、逐题演练、结束后给总结。

---

## 一、什么时候才轮到练面试

面试是漏斗的第三层。前两层没通，练面试是浪费。

| 你的数据 | 现在该做什么 |
|---|---|
| 投递 20+，沟通 0 | 不是面试问题，回 M6 |
| 沟通 5+，面试邀请 0 | 不是面试问题，查话术与到岗时间 |
| 面试 3+，offer 0 | **才轮到本节** |
| 已有面试安排 | 直接进模拟 |

## 二、模拟面试：准备

### 2.1 需要用户提供

| 项 | 形式 | 必需 |
|---|---|---|
| 岗位描述 | 截图或文本 | 必需 |
| 简历 | PDF 或文本 | 必需 |
| 面试轮次 | 一面 / 二面 / HR 面 / 终面 | 可选，默认一面 |
| 公司/行业 | 文字 | 可选 |

**缺岗位描述**：不发散出题，改为"通用行为面 + 简历深挖"，并说明这是降级模式。

### 2.2 出题逻辑：四步从 JD 和简历生成问题

**不要背题库。** 固定 15 题只能覆盖 60%，剩下 40% 是"这家公司这个岗位最近在问什么"。方法是现推。

#### 第一步：把 JD 拆成三类词

| 类型 | 怎么认 | 例（数据运营岗） |
|---|---|---|
| **硬技能** | 工具名、方法名、证书 | SQL、Power BI、Excel、漏斗模型、A/B 测试 |
| **业务场景** | 品类、平台、流程环节 | 电商店铺、大促、SKU、转化率、复购率 |
| **软要求** | 形容词 + 行为动词 | 跨部门协作、抗压、主动复盘、结果导向 |

**每个词都要在简历里落地一次。** 拆不出来的 JD，说明它是模板 JD（同一家公司挂多个岗位用同一段话），这种情况按"岗位名 + 行业常识"出题，并在总结里注明。

#### 第二步：拿每个词去简历里找锚点

| 简历上找到什么 | 出什么题 | 例子 |
|---|---|---|
| **有对应经历** | **深挖题**：问细节，问到你答不出为止 | "你写用漏斗模型拆解访客路径，具体拆了哪几段？各段流失率是多少？" |
| **有相关但不同** | **迁移题**：问能不能套过去 | "你做过电商转化分析，换成线下门店的客流分析，你会怎么改？" |
| **完全没有** | **缺口题**：问怎么补，不要回避 | "岗位要求 A/B 测试，你简历里没有。如果现在让你设计一个，你会怎么做？" |
| **简历高于 JD** | **上探题**：问上限与稳定性 | "你的项目做到全渠道，这个岗位只管单平台，你会不会觉得简单？" |

**缺口题必须出至少 2 道。** 这是面试官最会问、求职者最没准备的一类。模拟时不问，真实面试就会崩在这里。

#### 第三步：联网补该岗位的真实面经

模板题只能覆盖通用部分。补齐"这家公司最近在问什么"，用检索式：

```
"{岗位名}" 面经 {公司名}
"{岗位名}" 面试问题 应届
site:nowcoder.com "{岗位名}" 面经
site:xiaohongshu.com "{岗位名}" 面试 复盘
```

**筛选规则**：

| 要 | 不要 |
|---|---|
| 近一年内、写明轮次与公司 | 时间不明、公司不明的"通用面经" |
| 高频重复出现的题 | 只出现一次的偏题 |
| 有具体追问链路的复盘 | "面试必过 100 题"这类引流标题 |

引用时标 `[检索·yyyy-mm·来源]`。**岗位题库一年就会换一轮，去年的一面积累不能直接用。**

#### 第四步：配比

总数 8–12 题，从四个来源取：

| 来源 | 题量 | 例子 |
|---|---|---|
| **JD 硬要求** | 3–4 | "这个岗位要求数据分析，你做过什么分析？" |
| **简历深挖** | 3–4 | "你写转化率提升，具体怎么算的？" |
| **动机与匹配** | 2–3 | "为什么投这个岗位？" |
| **压力与情境** | 1–2 | "领导临时改需求，你怎么办？" |

**必须包含至少 2 道"追问三层"的题**（见 4.3），这是最容易崩的地方。

**出完题先自检一句**：这些题里，有几道是"只有这个岗位才会问"的？如果全是通用题，说明第一步没做——JD 拆得不够细。

## 三、模拟面试：流程

### 3.1 规则

```
1. 一次只问一题，等用户答完再问下一题
2. 不中途点评、不打断（除非超过 3 分钟）
3. 每题最多追问 2 层
4. 全程结束后一次性给总结
```

**为什么不中途点评**：真实面试不会给你反馈。中途点评会让用户按提示调整，测不出真实水平。

### 3.2 开场话术

> "我们现在开始模拟面试，岗位是 __，一共 __ 题。我会一次问一题，你直接答，我不打断。全部结束后我再给总结。第一题：请先做一个 60 秒的自我介绍。"

### 3.3 单题限时

| 题型 | 建议时长 |
|---|---|
| 自我介绍 | 60 秒 |
| 行为题 | 90 秒 |
| 专业题 | 2 分钟 |
| 反问 | 不限 |

超时提示一次："时间到了，先停在这里。"不评价。

### 3.4 追问样例

| 用户答 | 追问 |
|---|---|
| "我提升了转化率" | "提升了多少？怎么算的？"→"基准是什么？" |
| "我负责数据分析" | "具体分析什么？用了什么方法？结论是什么？" |
| "我们团队完成了" | "你个人负责哪部分？" |
| "我学到了很多" | "举一个具体的例子。" |

## 四、必备三件套（模拟前先准备）

| # | 产出 | 要求 |
|---|---|---|
| 1 | 自我介绍 60 秒 | 能不看稿说完，不复述简历 |
| 2 | 3 个项目故事 | 每个能讲 3 分钟，扛得住三层追问 |
| 3 | 5 个反问 | 问岗位、团队、考核，不问福利 |

### 4.1 自我介绍结构

```
身份（学校+专业+毕业时间）
+ 1 个与岗位相关的成果（带可验证的结果）
+ 为什么投这个岗位（一句具体的话）
```

### 4.2 项目故事：STAR

```
S 情境：什么背景下，什么问题
T 任务：你负责什么（不是团队负责什么）
A 行动：你具体做了什么（3 步以内，动词开头）
R 结果：结果是什么（只写扛得住追问的数字）
```

### 4.3 追问三层（必须提前自测）

| 层 | 问题 | 答不出说明 |
|---|---|---|
| 1 | 这个数字怎么算的？ | 数字是编的 |
| 2 | 基准是什么？和谁比？ | 没有对照组 |
| 3 | 你个人贡献占多少？ | 把团队成果写成个人成果 |

**任何一层答不出，就把这个数字从故事里删掉，改成过程描述。**

## 五、高频问题与答法（15 题）

### 5.1 行为面（5 题）

| # | 问题 | 答法要点 | 禁忌 |
|---|---|---|---|
| 1 | 讲一个你主导并落地的项目 | 背景一句话、你的动作三步、可量化结果 | 把团队成果写成个人 |
| 2 | 讲一次失败或搞砸的经历 | 事实 + 你的判断失误 + 具体修正 | 甩锅、"没失败过" |
| 3 | 你和队友冲突怎么处理 | 冲突点、你让步的边界、最后共识 | 说"我们从不冲突" |
| 4 | 时间紧任务多怎么排优先级 | 排序依据（影响面 / 截止时间）、你砍掉了什么 | 说"我都能做完" |
| 5 | 你最大的缺点 | 一个真实但可控的短板 + 正在用的方法 | "我太追求完美" |

### 5.2 专业面（5 题）

| # | 问题 | 答法要点 | 禁忌 |
|---|---|---|---|
| 6 | 你对我们这个岗位的日常工作理解是什么 | 用 JD 里的三个动词复述 + 一句你的匹配点 | 背官网介绍 |
| 7 | 给一个业务场景，现场拆解 | 先说目标、再说变量、最后给验证方式 | 直接报答案 |
| 8 | 你做过最像这件事的经历 | 挑最近的一个，讲清"我负责哪一段" | 讲三年前的无关经历 |
| 9 | 你常用什么工具/方法，到什么程度 | 说得出具体功能与产出物 | 堆名词 |
| 10 | 如果数据和你预期相反，你怎么办 | 先查口径、再查样本、最后才改结论 | "以数据为准"这种空话 |

### 5.3 动机面（5 题）

| # | 问题 | 答法要点 | 禁忌 |
|---|---|---|---|
| 11 | 为什么选这个行业 / 这家公司 | 行业一句、公司一句、你的一句 | 背官网 |
| 12 | 为什么不做本专业（不从事本专业者必考） | 触发点 + 已验证的动作（课程/项目/实习）+ 可迁移能力 | 贬低本专业 |
| 13 | 未来 3 年你想成为什么样的人 | 能力目标，不是职级目标 | "想做到主管" |
| 14 | 你期望薪资多少 | 先问区间、再给自己的区间、给依据（同城同岗 + 你的稀缺点） | "都可以" |
| 15 | 你有什么问题问我们 | 见第六节 | "没有了" |

### 5.4 最容易崩的 5 道

**第 12（不从事本专业的理由）、第 2（失败经历）、第 5（缺点）、第 14（薪资）、第 15（反问）。**

共同点：**都需要自我暴露或谈判**，没有标准答案，背模板会立刻露馅。这五题要单独练，不放进通用题流。

## 六、反问清单（选 2–3 个）

**问岗位与团队**

- 这个岗位试用期的核心考核指标是什么？
- 团队目前多少人？我向谁汇报？
- 这个岗位目前最大的挑战是什么？
- 新人前 3 个月通常会遇到什么问题？

**问成长**

- 团队里做得好的同事，通常具备什么特点？
- 这个岗位未来一年最主要的业务方向是什么？

**不要问**（留到 offer 阶段）

- 加班多吗 / 周末上班吗
- 工资多少 / 有没有年终奖
- 能不能远程 / 能不能晚到

## 七、模拟面试总结（结束后一次性给）

### 7.1 评分表

| 维度 | 1–5 分 | 依据 |
|---|---|---|
| **结构** | | 回答有没有层次，是否先给结论 |
| **证据** | | 有没有具体例子与可验证结果 |
| **匹配** | | 是否贴着岗位要求答，而不是泛泛而谈 |
| **表达** | | 是否有口头禅、跑题、超时 |

### 7.2 三个改进点（按影响排序）

```
① 最影响结果的一处：__（原话摘录）→ 改为：__
② 第二处：__
③ 第三处：__
```

**必须摘原话**。"表达不够好"不是建议，"你说了三次'然后就是'，删掉"才是。

### 7.3 一句话判断

> "这场模拟的水平，相当于真实面试的 __ 分（100 分制）。最该改的是 __。"

### 7.4 是否重答

| 情况 | 处理 |
|---|---|
| 某题明显崩了 | 给 1 次重答机会，答完只对比差异，不再评分 |
| 整体低于 60 分 | 不重答，先改三件套再约第二次 |
| 整体 60–75 分 | 改三个点，3 天后再模拟一次 |
| 整体 > 75 分 | 停止模拟，去投真实面试 |

## 八、本模块不覆盖

| 类型 | 去哪里 |
|---|---|
| 群面 / 无领导小组 | `job-companion-team` 的 `mock-interview` |
| 笔试 / 在线测评 | 目标公司真题、牛客网 |

## 九、判停

> 练几次、什么时候练，他定。这里只给"这个信号说明问题在哪"。

| 信号 | 说明什么 | 通常有效（不是必须） |
|---|---|---|
| 一次面试都还没有 | 现在练的是表达，不是应答 | 可以先练结构与时长，不必系统刷题 |
| 面试 3 次 0 offer | 表达过关了，卡在应答与匹配 | 才值得系统练 |
| 连续 3 次一面挂 | 不是技巧问题，是匹配度 | 回方向查匹配，不要继续刷题 |
| 自我介绍超过 90 秒 | 结构没压住 | 砍到 60 秒 |
| 模拟 2 次仍 < 60 分 | 不是练得不够，是三件套没准备 | 先改简历与项目陈述，不重答 |
| 每次真实面试后不复盘 | 同样的错会重复，且记不住细节 | 当场记 3 条：最好的一题、最差的一题、下次改什么 |
