# L1 恒定判据总表

> 这一份的内容**不随城市与年份变化**，引用时标 `[规则]`。
> 若某条被真实数据证伪，**不要删除**——改标 `[已失效]`，写清失效条件与证伪证据。

## 一、计算式

变量一律由用户填，skill 不预设任何绝对值。

### 1.1 可承受月租

```
可承受月租 = 税后月薪 − 吃饭 − 通勤 − 通讯 − 日用 − 净收入底线 − 强制储蓄
```

- **税后**：到手，不是税前，不是"总包÷12"
- **净收入底线**：扣掉房租与吃喝后每月至少要剩多少
- **强制储蓄**：先扣再花

结果为负 → 这份工作在独立生活前提下不可行，不是"再省省"。

### 1.2 首次入住现金需求

```
押一付一：押金 1 + 首期 1 + 中介费 0.5 ≈ 2.5 个月租金
押一付三：押金 1 + 首期 3 + 中介费 0.5 ≈ 4.5 个月租金
另加：床品、厨具、清洁、宽带初装、搬家
```

### 1.3 通勤时间成本

```
每月通勤小时 = 单程分钟 × 2 × 月工作日 ÷ 60
```

### 1.4 时薪折算（判断长通勤是否值得）

```
时薪 = 税后月薪 ÷ (21.75 × 8)
租金差额 ÷ 每月多耗小时  >  时薪  →  省下的房租不值这些时间
```

### 1.5 应急金

```
应急金 = 3–6 个月全部支出
在校：1 个月｜求职期：2–3 个月｜入职后：3–6 个月
```

### 1.6 异地实习准备金

```
1–2 个月生活费，约 5,000–10,000 元
```

**用途**：决定去外地实习前的硬门槛。没备齐不去，不是"到了再说"。

### 1.7 储蓄率

```
储蓄率 = 储蓄 ÷ 收入
在校 10% 起步；入职后 20–30%
```

## 二、顺序规则（不可颠倒）

### 2.1 城市与岗位

```
定赛道 → 查该赛道在哪些城市密集 → 查上下游配套
→ 评估同城跳槽容错率 → 才排城市
```

### 2.2 落地顺序

```
定城市 → 定片区 → 定房源 → 定合同
```

先签约等于把自己钉死在通勤半径里，岗位池被迫缩小。

### 2.3 落脚顺序

```
临时落脚（1–2 周）→ 稳定观察（1–3 个月）→ 长租
```

不要在入职前签一年长租。公司、片区、试用期三项都未定。

### 2.4 求职动作顺序

```
盘资产 → 定方向 → 改简历 → 投递 → 面试 → 谈 offer
```

不知道投什么时改简历，改的是措辞不是匹配度。

### 2.5 入职动作顺序

```
第 1 周对齐 KPI → 前 2 个月留可量化证据 → 转正前 1 个月做述职
```

## 四、核验清单

### 4.1 租房合同

| 项 | 核验内容 | 不合格 |
|---|---|---|
| 出租人身份 | 身份证 + 房产证，姓名一致 | 不签 |
| 转租授权 | 二房东须出示**原房东书面授权** | 不签 |
| 租金押金 | 金额、押几付几、付款日 | 只口头不签 |
| 附加费用 | 物业、网费、水电单价与承担方 | 不写清不签 |
| 水电性质 | 民用还是商用 | 合同注明 |
| 退租条款 | 通知期、违约金、是否可转租 | 不写不签 |
| 维修责任 | 哪些房东修、响应时限 | 不写不签 |
| 房屋现状 | 全屋录像 + 水电表底数 + 家具清单 | 未记录不交钥匙 |
| 合同份数 | 一式两份，自留原件 | 只签一份不签 |
| 贷款条款 | 任何"租金贷/分期付" | 一律拒绝 |

### 4.2 劳动合同

| 项 | 核验内容 |
|---|---|
| 主体 | 公司名称与面试公司一致，有公章 |
| 期限 | 固定/无固定/以完成一定工作为期限 |
| 试用期 | 时长与合同期限匹配；同一单位只能约定一次 |
| 工作内容与地点 | 岗位名称、地点写明 |
| 工时制度 | 标准 / 综合计算 / 不定时 |
| 薪酬结构 | 无责底薪、绩效、补贴、发放日 |
| 社保公积金 | 基数、起缴月份 `[待核]` |
| 竞业与保密 | 是否限制、有无补偿 |
| 违约条款 | 服务期、培训费、违约金 |
| 份数与签字 | 一式两份、盖章、自留原件 |

**试用期法定参考** `[规则·以现行《劳动合同法》为准]`

| 合同期限 | 试用期上限 |
|---|---|
| 不满 3 个月 / 以完成一定工作任务为期限 | 不得约定 |
| 3 个月以上不满 1 年 | ≤ 1 个月 |
| 1 年以上不满 3 年 | ≤ 2 个月 |
| 3 年以上 / 无固定期限 | ≤ 6 个月 |

**试用期工资**：不低于本单位同岗位最低档工资或合同约定工资的 80%，且不低于当地最低工资。

- 身份证、毕业证、学位证（应届按报到时间补交）
- 一寸/两寸照片、工资卡

## 五、价值排序

**多 offer 或城市对比时，按此顺序，不做加权平均：**

```
岗位业务 > 直属领导 > 薪资结构 > 公司平台 > 成长速度 > 工时通勤 > 城市
```

**理由**：决定下一份工作质量的是"你做过什么核心业务"，不是"你在哪座城市"。

**推论**：

- 边缘业务岗 + 好城市 **<** 核心业务岗 + 普通城市
- 城市是 3–5 年的跳板，不是定居承诺
- 拿到真实 offer 之前，不做最终城市决策

## 六、待核项（不得当作结论使用）

| 项 | 为什么待核 | 怎么核 |
|---|---|---|
| 社保起缴时点 | 各地执行口径不同 | 问 HR 要书面说明；查当地社保局 |
| 公积金缴存比例 | 城市间差异大 | 当地公积金中心 |
| 试用期法定上限 | 以现行法律为准 | 签约前核对条文 |
| 人才驿站/青年驿站条件 | 各城政策、名额不同 | 当地人社局/团委官网 |
| 报到证是否仍需办理 | 政策已调整 | 学校就业指导中心 |
| 民水民电单价 | 各城阶梯价不同 | 供电局/水务局；或看房东近一期账单 |
| 落户条件 | 城市与学历差异大 | 当地公安户政 / 人社局 |

## 七、判据的失效与更新

**三种情况必须改判据：**

1. **真实数据证伪**：标 `[已失效]`，写清在什么条件下失效
2. **环境变化**：L2 项，直接更新并标新日期
3. **用户明确纠正**：记录为例外，不改成通用规则

**禁止**：因为一次失败就推翻整条判据。一次是样本，三次才是信号。

## 八、数值型判据：全部是「默认值」，不是「结论」

**这一节解决的是"阈值未验证"这个问题。**

skill 里所有数字（转化率区间、岗位池阈值、九维权重）都来自公开口径或推导，**没有一条来自实测**。

### 8.1 为什么这不构成缺陷

求职漏斗**因人而异**：同样是投 20 份简历，985 计算机硕士和独立学院文科生的回复率能差三倍。给你一个"通用正确值"，反而是误导。

**所以这些数字的正确身份是"默认值"**——在你还没有自己数据时，用来知道量级、避免期待错位。

### 8.2 默认值清单（哪些是默认值）

| 判据 | 默认值 | 来源 | 什么时候该被替换 |
|---|---|---|---|
| 投递 → 被查看 | 30–50% | 平台公开口径，未复核 | 有自己的数据时 |
| 被查看 → 沟通 | 20–30% | 同上 | 同上 |
| 沟通 → 邀约 | 20–30% | 同上 | 同上 |
| 邀约 → offer | 15–25% | 同上 | 同上 |
| 岗位池够大 | > 100 条/周 | 操作口径 | 有真实挂牌数时 |
| 城市九维权重 | 30/22/18/12/6/5/4/2/1 | 推导 | 跑过 3 个城市后 |

### 8.3 正确用法

| 情况 | 参照什么 | 目的 |
|---|---|---|
| 还没有自己的数据 | 默认值 | 知道大概量级，不抱错期待 |
| 已有自己的投递数据 | **你自己的实际转化率** | 只跟自己比，不跟别人比 |

**skill 不规定"投多少份之后该做什么"。**

什么时候改简历、改几轮、什么时候换方向，由用户自己判断。**诊断归 skill，决策归用户**——这条和 M4 的边界一致。

**唯一会主动提示的情况**：用户明确问"我是不是该调整了"，才给判断依据，但不替他定。

### 8.4 替换规则：用自己的基线当标尺

```
你的基线 = 已有数据的实际转化率
触发改进 = 某一层低于你自己基线的 70%
```

**不要再用"低于 30% 就有问题"这种绝对线。** 用你自己的 70%，因为它剔除了行业、城市、学历的差异。

**举例**：你的查看率基线是 45%，连续两批掉到 28%（62%），没到 70% 线，不用动；如果掉到 20%（44%），才该查简历入口。

### 8.5 默认值唯一的用途

> **防止"投 5 份没回复就觉得自己不行"这种过早放弃。**

它不是标准，是防跌线。**任何一批数据显示"远低于默认值"时，先怀疑样本太小，再怀疑判断。**

### 8.6 校准记录放哪

用户不需要写进 skill。**建议他记在自己的投递表里**：每批的四个原始数 + 算出来的三层转化率。

**skill 不需要变，变的是他手里的基线。**
