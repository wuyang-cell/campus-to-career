# M8 · 落脚与租房

> 解决什么：到陌生城市先住哪、什么时候租、怎么不被坑。
> 核心原则：**先落脚，后稳定，再租房。不要在入职前签长租。**
> **具体房源怎么找、怎么去重、怎么识别虚假房源、怎么算真实月成本：见 `references/93-housing-search.md`。** 本模块负责判断"什么时候该租什么"，93 负责"怎么把房源找出来并筛掉假的"。

**第一次租房选哪种模式，结论在 93 的 3.1：品牌长租公寓 > 中介 > 城中村。** 顺序不是按价格排的，是按"第一次租房最怕被骗，不是最怕贵"排的。预算低于 1000 元/月才考虑城中村，且必须有书面合同、能自己在 App 上缴水电。

## 〇、输出模板：城市一定下来，这三层一次给完

**这是假设模式的用法**：用户说"假设我选广州"，就直接按广州给全套住宿指引，不需要他真的拿到 offer、也不需要他真的过去。

```
【城市】__

【第一层 · 过渡住宿（0–7 天）】
  青年驿站：有 / 无 ｜ 免费 __ 天 ｜ 学历要求 __ ｜ 是否要面试通知 __ ｜ 申请入口 __
  青旅：__ 片区，床位 __ 元/晚，到工作区约 __ 分钟（已含早高峰系数）
  这一层总计：__ 元

【第二层 · 短租（1–4 周）】
  求职公寓 / 短租：__ 元/天 ｜ 位置 __
  这一层总计：__ 元（按 __ 天算）

【第三层 · 长租（3 个月起）】
  片区排序（按「通勤 + 真实月成本」排，不按离市中心远近）：
    1. __：单间 __ 元/月，门到门通勤 __ 分钟，真实月成本 __ 元
    2. __：单间 __ 元/月，门到门通勤 __ 分钟，真实月成本 __ 元
    3. __：单间 __ 元/月，门到门通勤 __ 分钟，真实月成本 __ 元
  首次入住现金：押 __ 付 __ + 中介费 __ + 首月杂费 ≈ __ 元

【注意事项】
  ① 电费：__ 元/度（民电约 0.6 / 商电约 1.3），夏天开空调月差 __ 元
  ② 押金退还条件：__
  ③ 二房东必查：原房东书面转租授权 + 房产证 + 身份证
  ④ 看房必拍：水电表底数、墙面与家电现状、门窗锁具

【会推翻这个方案的情况】
  ① offer 的工作地点在 __ 区 → 上面第 __ 片区作废
  ② 驿站排不上 → 直接进第二层，预算 +__ 元
  ③ __
```

**三条硬规则**：

1. **三层是接力的，不是并列的**（没面试只能住青旅，有面试才用得上驿站，拿 offer 才谈长租）
2. **价格写"真实月成本"，不写挂牌租金**（租金 + 水电 + 物业 + 网费 + 中介费摊销 + 通勤）
3. **片区按"通勤 + 成本"两个数排**，不按"离市中心远近"——离市中心近但通勤 70 分钟的地方，不如远一点但直达的

**必须标不确定的项**：租金是区间、政策有时效、通勤是估算。哪一项没核就写"未核"，不填一个好看的数。

## 二、三阶段

```
阶段一：临时落脚（1–2 周）  →  阶段二：稳定观察（1–3 个月）  →  阶段三：长租
```

**为什么不一步到位**：公司、片区、能否过试用期，三项都还没确定。任何一项变化，长租都会变成违约金。

---

## 三、阶段一：临时落脚

### 3.1 三种选择

| 类型 | 成本 | 适合 | 注意 |
|---|---|---|---|
| **人才驿站 / 青年驿站** | 免费或极低 | 毕业 2 年内、求职期 | 需提前申请，名额有限，条件各城不同 |
| **青旅** | 按天，低 | 1–2 周密集面试 | 注意财物安全，不适合长期 |
| **短租 / 长租公寓** | 按月，中 | 1–3 个月 | 押一付一，看清服务费 |

**推荐路径**：驿站/青旅（1–2 周）→ 跑完面试、确认片区 → 短租（1–3 个月）→ 确认转正后签长租。

### 3.2 政策检索清单（逐城查，逐条标日期）

| 项 | 要查到什么 |
|---|---|
| 人才驿站 / 青年驿站 | 申请条件（学历/毕业年限/社保）、免费天数、名额、申请入口 |
| 一次性就业补贴 | 金额、学历门槛、申领窗口、截止日期 |
| 租房补贴 | 金额、发放方式、是否需社保 |
| 落户政策 | 学历/社保要求、办理流程 |
| 创业/见习补贴 | 是否有、条件 |

**检索口径**：只查 A 级来源（人社局、团委、公安局户政、公积金中心官网），必须记录**发布日期**。政策每年变，2024 年的文章不能用于 2026 年。

**输出格式**：

```
[检索·2026-11·__市人社局] 青年驿站：毕业 2 年内、专科及以上、免费 7 天，需提前 3 天在 __ 小程序申请
```

### 3.3 动身前 6 项清单

| # | 项 | 完成标志 |
|---|---|---|
| 1 | 目标岗位已定 | 一个具体岗位名 |
| 2 | 求职半径已定 | 收藏 20–30 个岗位，统计出 1–2 个高频行政区 |
| 3 | 面试邀约已攒到 | ≥ 2 个可线下参加的面试 |
| 4 | 生活费已备 | ≥ 2 个月全部开支（见 M10） |
| 5 | 过渡住宿已定 | 已确认可入住日期与价格 |
| 6 | 材料已定稿 | 简历 PDF、作品集、证件扫描件 |

**6 项未齐 → 不动身。**

---

## 四、阶段二：稳定观察（1–3 个月）

这三个月只做三件事：

1. 确认这份工作能不能做下去（试用期风险见 M9）
2. 实测通勤：早晚高峰各走一次，记录真实时间
3. 摸清片区：哪条街便宜、哪个地铁站方便、哪里晚上不安全

**不要在这期间签一年长租。** 用短租或月付公寓过渡。

---

## 五、阶段三：长租

### 5.1 预算先行

```
可承受月租 = 税后月薪 − 吃饭 − 通勤 − 通讯 − 日用 − 净收入底线 − 强制储蓄
```

| 项 | 怎么填 | 常见错误 |
|---|---|---|
| 税后月薪 | 到手，不含年终 | 用税前或"总包÷12" |
| 吃饭 | 按当地实际 | 低估 30% |
| 通勤 | 月卡 + 偶尔打车 | 只算月卡 |
| 日用 | 洗漱、纸巾、清洁、话费 | 漏算 |
| 净收入底线 | 扣掉房租吃喝后至少要剩多少 | 填 0 |
| 强制储蓄 | 先扣再花 | 填"看情况" |

**算完立刻写死上限。** 超出的一律不看——看了就会想突破。

### 5.2 首次入住现金需求

```
押一付一：押金 1 个月 + 首期租金 1 个月 + 中介费 0.5 个月 ≈ 2.5 个月租金
押一付三：押金 1 个月 + 首期租金 3 个月 + 中介费 0.5 个月 ≈ 4.5 个月租金
另加：床品、厨具、清洁、宽带初装、搬家
```

### 5.3 片区：先于房源

```
1. 收藏 20–30 个目标岗位
2. 统计公司所在行政区频次
3. 取前 1–2 个区 = 求职半径
4. 在该半径内或地铁直达范围找房
```

**通勤上限**：单程 60 分钟。超过必须有明确理由（租金差额显著大于时间成本）。

**时间成本算法**：

```
每月通勤小时 = 单程分钟 × 2 × 月工作日 ÷ 60
时薪 = 税后月薪 ÷ (21.75 × 8)
判断：租金差额 ÷ 每月多耗小时 > 时薪 → 不值得
```

### 5.4 房源：我能做什么、不能做什么

| 能做 | 不能做 |
|---|---|
| 按城市给**预算上限 + 目标片区 + 筛选条件** | 实时抓取贝壳/58/小红书的完整房源列表 |
| 评估用户发来的**链接或截图**（通勤、价格、水电、合同、性价比） | 保证房源真实存在、不被租掉 |
| 给"这条房源该问房东哪 8 个问题" | 代替用户看房、签约 |

**用户发链接/截图时，按六维评估**：

| 维度 | 看什么 | 红旗 |
|---|---|---|
| 通勤 | 到公司的实测时间与换乘 | 地图显示 40 分钟，实际换乘 3 次 |
| 价格 | 是否低于同片区均价 30% | 明显偏低 = 引流 |
| 水电 | 民用还是商用 | 商用未提前说 |
| 硬件 | 空调、洗衣机、热水器、漏水、隔音 | 只有美图，无实拍 |
| 合同 | 押付方式、退租条款、维修责任 | 只口头承诺 |
| 安全 | 楼层、门禁、周边 | 一楼偏僻、无门禁 |

### 5.5 看房与签约

看房清单用 `assets/viewing-checklist.md`（通勤/硬件/水电/合租/安全五类）。
合同核对用 `assets/contract-checklist.md`（12 项，任一项不合格不签）。

**三条不可退让**：

1. 二房东必须出示**原房东书面转租授权**
2. 任何"租金贷/分期付"一律拒绝
3. 入住当天全屋录像 + 水电表底数

### 5.6 五个最容易被忽略的条款

不是"注意避坑"这种笼统提示，是**原文怎么写、风险在哪、改成什么**。签约时逐条对。

| # | 合同里可能这样写 | 风险 | 改成 |
|---|---|---|---|
| 1 | "水电费按商业标准收取，电费 __ 元/度，由乙方承担" | 这是加价。《供电营业规则》（2024 年发改委令第 14 号）第十七条明确：非电网供电主体应按政府规定电价执行，**不得在终端用户电费中加收**。广州市场监管部门已对多起加价立案处罚 | "电费按居民合表电价据实结算，甲方提供缴费凭证或分摊明细，不得加价或另立管理费" |
| 2 | "押一付三，乙方提前退租的，押金不予退还" | 押金无上限、无验收标准，退租必被扣 | 写明押金金额、"退租验收后 7 日内退还"、可扣减情形清单及单项上限 |
| 3 | "甲方有权提前 30 日通知收回房屋" | 随时被清退且不赔 | 租期内非乙方违约不得单方解除；因产权变动需收回的，赔偿 1 个月租金并给 30 日搬迁期（《民法典》第 725 条：买卖不破租赁） |
| 4 | "房屋及附属设施的维修费用由乙方承担" | 空调、热水器、水管坏了全归你 | 自然损耗及非乙方原因由甲方承担，报修 48 小时内响应；单次维修超过约定金额由甲方承担 |
| 5 | "本合同一式一份，由甲方保管" | 出事无凭证、无法举证 | 一式两份，双方各持一份，附房屋交接清单（含水电表底数、家电状况照片） |

**通用原则**：口头承诺一律写进合同，否则视为不存在。

### 5.6.1 二房东：要核验三份材料

只问"你有授权吗"不够，要看三样东西：

| # | 材料 | 看什么 |
|---|---|---|
| 1 | 原房东与二房东的租赁合同 | 租期是否**覆盖**你的租期（他的合同先到期，你就得走） |
| 2 | 原房东**书面**同意转租的证明 | 《民法典》第 716 条：未经同意转租，出租人可解除合同 |
| 3 | 二房东近期的付租凭证 | 他欠租，你的合同跟着失效 |

**加分两项**：房屋产权证复印件、原房东身份证复印件。

### 5.7 民水民电与商水商电：差多少

**先看官方目录价，再看房东报价——这两者往往不是一回事。**

| 城市 | 居民价 | 非居民价 | 倍数 | 依据 |
|---|---|---|---|---|
| 北京（电） | 一档 0.4883 元/度 | 不满 1 千伏平段 0.8745、尖峰 1.5295 | 约 1.8–3.1 倍 | 北京发改委电价表 |
| 深圳（水） | 2.67 元/m³ | 4.76 元/m³ | 1.78 倍 | 深发改〔2025〕354 号，2025-07-01 起 |
| 广州从化（水） | 1.66 元/m³ | 2.25 元/m³ | 1.36 倍 | 从化区发改局，2025-03-01 起 |
| 青岛城阳（水） | 综合 3.50 元/m³ | 综合 5.40 元/m³ | 1.54 倍 | 城阳区政府价格公示 |

`[检索·2026-11·各地发改委/水务局]` 各城阶梯价不同，签约前以当地公布为准。

**但租客实际承担的是房东报价。** 广州 2024–2025 年通报的违规案例中，加价后普遍到 1.2–1.6 元/度，是居民电价的 2.5–3 倍；单笔罚款最高 75.5 万元。按单人每月 30–50 度电、3–5 吨水估算，商电合租比民电合租每月多约 40–60 元，**一年约 500–700 元**（估算值，非官方统计）。

**判断方法（现场可做）**：让房东出示最近一期水电费单，用「总金额 ÷ 度数」反推单价。说不清或拿不出的，按商用价预估成本再谈租金。

## 六、判停

| 信号 | 说明什么 | 我这边怎么接 |
|---|---|---|
| 已有落脚点 | 本模块目的已达成 | 跳出，进合同核对 |
| 6 项动身清单未齐 | 到异地会断钱或断住处 | **风险项，没有商量余地**：不动身 |
| 面试邀约 < 2 | 还没有必须到场的理由 | 继续线上投，先不买票 |
| 存款 < 2 个月开支 | 到异地撑不到第一份工资 | 先攒钱 |
| 看 5 套仍无合适 | 约束叠加过头 | 放宽一项（预算 +10% / 通勤 +15 分钟 / 接受合租） |
| 房源低于同片区均价 30% | 低于市价必有原因 | **风险项**：先查原因，不捡漏 |
| 合同任一项核对不过 | 签字后追偿成本高 | 不签，换房 |
| 尚未入职、未确认转正 | 公司、片区、试用期三项都未定 | 只签短租或月付 |
| 已到城市 2 周无面试 | 投递口径或地域问题，不是"城市不行" | 复盘投递，不是换城市 |
