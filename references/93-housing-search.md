# 93 · 房源检索（由岗位检索逆向拆解而来）

> 解决什么：把"找房"从刷 App 变成一条有降级路径、有去重规则、有判停标准的流程。
> **方法来源**：把 `92-job-search.md` 的流程骨架迁移到租房场景。骨架可迁移，但**有四个环节必须重写**，照搬会失败。

---

## 〇、逆向拆解：哪些能搬，哪些不能

岗位检索的七个环节，迁移到房源时的处置：

| # | 环节 | 找岗位 | 找租房 | 处置 |
|---|---|---|---|---|
| 1 | 必填参数 | 岗位、城市、薪资 | 城市、预算、**通勤上限**、房型、租期 | **加一项**：通勤上限是租房独有的硬约束 |
| 2 | 渠道矩阵 | BOSS/猎聘/智联 | 贝壳/自如/58/闲鱼/豆瓣/本地房东 | **照搬结构**，换名单 |
| 3 | 五级降级链 | CLI→HTTP→聚合→详情→人工 | App→网页→聚合→详情→**实地** | **末环换成实地**，不是人工 |
| 4 | 活跃优先 | 剔除已关闭 | 剔除已租出 | **照搬**，语义相同 |
| 5 | 去重主键 | 公司+岗位+城市 | **小区+户型+面积+楼层** | **必须重写**，见第二节 |
| 6 | 输出结构 | 速览表+完整 JD | 速览表+**通勤时间+真实月成本** | **必须重写**，见第五节 |
| 7 | 判停 | 抓不到就降级 | 看 5 套无合适就放宽约束 | **照搬** |

**一句话**：骨架能搬，因为都是"多源采集 → 降级兜底 → 去重 → 输出"；但**房源的三个属性**（可造假、必须实地看、成本不透明）让中间三环必须重做。

### 0.1 一条更准的判据：看这个环节依赖什么

"输入物是否同构"基本够用，但不够精确。更准的判据是：

| 这个环节依赖的是 | 例子 | 能否照搬 |
|---|---|---|
| **项本身的属性** | 渠道不够了怎么办（降级链）、投多少该停（判停）、只保留在招的（活跃优先） | **能搬**，换成领域词即可 |
| **项与外部的关系** | 两个项是不是同一个（去重键）、这个项要展示哪些字段（输出结构）、它到底要花多少钱（成本核算） | **必须重写** |

岗位和房源都是"待选清单项"，所以降级链、活跃优先、判停能搬；但"两个项是否同一个"在岗位里是公司+岗位名，在房源里是物理空间，不同构，所以去重键必须重写。

**这条判据可以复用到别处**：找实习、找供应商、选学校、找短租，都是同一个骨架。

**两个"看起来同构、实际不能搬"的陷阱**：

| 陷阱 | 为什么不能搬 |
|---|---|
| 找工作 → 找实习 | 去重键要加"部门"（同公司不同部门算不同岗）；且实习不签三方、不谈薪 |
| 找长租 → 找短租 | 去重键要加"时间窗"（同一套房这周有房和下周有房，是两回事） |

## 一、必填参数（缺就追问，不猜）

| 参数 | 说明 | 示例 |
|---|---|---|
| 城市 + **工作地点** | 没有工作地点，通勤无法算 | 广州·珠江新城 |
| **预算上限**（月） | 用 `90-rules.md` 的租房预算恒等式算，不是拍脑袋 | 1500 元 |
| **通勤上限**（单程分钟） | 租房独有的硬约束 | 45 分钟 |
| 房型 | 单间 / 合租 / 一房一厅 | 合租单间 |
| 租期 | 3 个月 / 半年 / 1 年 | 半年起 |
| 是否接受城中村 | 决定价格区间是 400 还是 1500 | 接受 |

**工作地点必须最先确定。** 没有它，所有"通勤 30 分钟"都是空话。这也是为什么租房必须在 `M5 定城市` 与 `M6 拿 offer` 之后。

## 二、四个必须重写的环节

### 2.1 虚假房源：价格排序不能直接用

**岗位不会造假，房源会。** 低价引流是行业惯例：挂一套不存在的 800 元精装单间，你打电话过去，对方说"刚租掉了，我带你看别的"。

**所以"按价格排序"这一步在租房里是有毒的。** 排在最前面的往往是假的。

**识别信号**（命中两条以上直接跳过）：

| 信号 | 说明 |
|---|---|
| 标价低于同片区均价 **30% 以上** | 真房源不会便宜这么多 |
| 图片过于精致（酒店式布光）但价格过低 | 精修图 + 低价 = 引流 |
| 同一组图片出现在多个不同房源 | 盗图 |
| 只写"XX 地铁站附近"，不写小区名 | 无法核实 |
| 要求"先交意向金再看房" | 直接拒绝 |
| 电话里说"这套刚租掉" | 经典话术，换下一家 |
| **图片真、描述假**：写"朝南"实朝北、写"独卫"实公用、写"近地铁"实走 20 分钟 | 比盗图更难识别，只能实地核 |
| **钓鱼房源**：图是盗的但价格真实，约到现场说"刚租掉，带你看另一套更好的" | 只发房不回细节、约看时间含糊，就是钓鱼 |

### 2.2 必须实地：线上只做初筛

**岗位看完 JD 就能判断要不要投，房源看完照片不能判断要不要租。**

线上判断不了的：采光（照片能调）、噪音（临街/临电梯/临垃圾站）、水压、霉味、隔音、邻居、实际通勤（步行到地铁的距离）。

**所以降级链的最后一环不是"人工提示"，是"实地"**：

```
App/小程序 → 网页 → 搜索引擎聚合 → 详情页 → 实地看房
```

**最低标准：签约前至少实地看 3 套。** 只看 1 套就签，等于把判断权交给中介。

**通勤时间要加早高峰系数**：

| 项 | 处理 |
|---|---|
| 地图 App 给的时间 | 是**平峰**时间，不能直接采信 |
| 早高峰修正 | **+15–25%**。地铁运行时间不变，但进站限流、排队上车、换乘步行会多 10–15 分钟 |
| 判断阈值 | 单程 > 60 分钟偏痛苦，> 90 分钟基本无法长期坚持 |
| 月通勤小时 | 单程 × 2 × 22。**超过 40 小时/月要慎重**（每周 10 小时） |

`[通用·2026·需按城市与线路校准]` 满载率高的线路修正更多；限流大站要单独加时间（一线城市的核心换乘站都在此列）。

### 2.3 真实月成本：挂牌租金不是成本

**岗位的薪资是明的，房源的租金藏着五项。**

```
真实月成本 = 租金
           + 水电（按性质估，见下）
           + 物业费（城中村常含，小区常另收）
           + 网费（常见 50–100 元/月，或含在房租）
           + 中介费摊销（通常半个月到一个月租金，按租期摊）
           + 通勤月票
```

**水电是最大的隐藏差价**：

| 类型 | 电价 | 夏天开空调的月差 |
|---|---|---|
| 民水民电 | 约 0.6 元/度 | 基准 |
| 商水商电 / 房东加价 | 约 1.2–1.5 元/度 | 多 200–500 元/月 |

**怎么算**：

```
问三句：上个月这间房用了多少度电、交了多少钱？夏天开空调一个月电费多少？是独立分表还是总表？
反推：总价 ÷ 度数 = 实际单价
估不出来：按 1.3 元/度 × 100 度 + 商水 5 元/吨 × 3 吨 ≈ 150–200 元/月，直接加进房租再比价
```

**法规上，加价是不允许的。** 《电力法》禁止在电费中加收其他费用；部分城市另有地方条例（如《广州市供用电条例》2023 年 5 月施行，明确对自然人加价收电费违规）。但城中村"总表分表"下，房东会以"线损公摊"辩解，执法有滞后，所以 1.2–1.5 元/度仍普遍。

**正确做法不是当场拒付**——合同在房东手里，拒付的结果是让你走。而是：

1. 先按房东的价住，保留缴费记录与聊天记录
2. 退租时打 12345 / 12315 投诉，要求退还差价
3. 签约时仍可提"按供电局账单据实结算"，城中村房东基本会拒绝——那就把它算进真实成本，或换房，不要在这上面僵持

### 2.4 去重主键不同

岗位去重是"同公司 + 同岗位"。房源不一样：**同一套房会被多个中介发**，房源编号不同、照片相同或略有裁剪。

```
房源去重主键 = 小区名 + 户型 + 面积（±3㎡）+ 楼层区间
```

命中主键 → 合并，保留最低报价，并**标注"多中介发布"**。

**但"多中介挂同一套"不能直接等同于"房东急租"。** 有两种相反的解释：

| 情况 | 判断 |
|---|---|
| 报价比同小区同户型低 **10% 以内** | 大概率急租，议价空间大 |
| 报价低 **20% 以上** | 大概率房子有硬伤（噪音、漏水、隔断、采光），**必须现场看为什么便宜** |
| 同平台挂了两个月还没租出 | 直接问"为什么这么久没租出去"，答案往往就是问题本身 |

## 三、渠道矩阵（按真假率排序，不按数量）

| 渠道 | 类型 | 真房源率 | 中介费 | 适合 |
|---|---|---|---|---|
| **贝壳 / 链家** | 中介 | 高（有房源核验码） | 半个月–1 个月租金 | 第一次租房，怕被骗 |
| **自如 / 泊寓 / 万科泊寓** | 品牌公寓 | 高 | 无中介费，有服务费 | 想省事、能接受溢价 |
| **本地房东直租（实地扫楼）** | 个人 | 高 | 无 | 城中村，最便宜 |
| 58 同城 / 安居客 | 混合 | **低**，低价引流多 | 视房源 | 只用来摸片区价格 |
| 闲鱼 / 豆瓣小组 / 小红书 | 个人转租 | 中（真实但少） | 无 | 短租、转租、捡漏 |

**结论**：摸价格用 58/安居客，找真房源用贝壳/自如，捡漏用闲鱼/豆瓣，最便宜靠实地扫楼。

### 3.1 第一次租房选哪种模式（不是选渠道，是选模式）

| 模式 | 适合 | 代价 |
|---|---|---|
| **品牌长租公寓**（自如/泊寓类） | **推荐给第一次租房的人** | 比城中村贵 30–100%，另收服务费 |
| **中介**（贝壳/链家类） | 想省心、要房源核验 | 中介费半个月到一个月租金；毕业季常有折扣，议价空间 10–20% |
| **城中村房东直租** | 预算 < 1000 元/月 | 水电加价、合同不规范、涨租随意 |

**推荐顺序：品牌公寓 > 中介 > 城中村。**

理由不是"哪个便宜"，而是**第一次租房最怕的不是贵，是被骗**。品牌公寓贵但合同规范、退租有标准流程；中介贵但房源真、有纠纷处理；城中村最便宜，但第一次租房的人不会验房、不会签合同、不会维权，一次踩坑的成本（押金 + 中介费 + 搬家）就超过一年省下的房租。

**品牌公寓的两个常见坑**：

| 坑 | 概率 | 怎么避 |
|---|---|---|
| **退租扣款** | 高，几乎每家都有 | 入住时逐项拍照录像、拍水电表底数、把"正常损耗"写进合同 |
| 甲醛 | 低但后果重 | 要求看 CMA 空气质量检测报告、选空置 3 个月以上的房、自己买检测仪（几十元）复测 |

## 四、检索式（可直接用）

```
site:ke.com 广州 {片区} 合租
site:douban.com 广州 {片区} 转租
小红书：{城市} {片区} 租房 转租
```

**个人转租的搜索词比"租房"更有效**：「转租」「急转」「到期转」——这类房源有明确时间压力，议价空间大。

## 五、输出结构

```markdown
# 房源清单 — {城市}·{片区} — {日期}

## 前置
工作地点：__ ｜ 通勤上限：__ 分钟 ｜ 预算上限：__ 元/月

## 速览表
| # | 小区/公寓 | 房型 | 挂牌租金 | 真实月成本 | 通勤（门到门） | 水电 | 渠道 | 状态 |

## 每套的具体判断
- 真实性：通过 / 存疑（原因）
- 通勤：步行 __ 分 + 地铁 __ 分 + 步行 __ 分 = __ 分
- 隐藏成本：__
- 待实地确认：采光 / 噪音 / 水压 / 霉味 / 实际距离

## 数据来源说明
各渠道用的方式、失败与降级记录、抓取时间
```

**通勤必须写"门到门"**，不是"地铁 3 站"。步行到地铁、换乘、出站到公司，这三段常被忽略，加起来能差 20 分钟。

## 六、还没面试，要不要先过去

**不要。这是最容易亏钱的一步。**

| 阶段 | 该做什么 | 为什么 |
|---|---|---|
| 还没投 / 刚投 | **留在原地线上投** | 初面基本都是视频面，跑过去也还是视频 |
| 拿到初面 | 在学校或家里视频面 | 省住宿费 |
| 拿到终面 / 复试 | **这时才过去** | 终面才需要到场 |
| 终面期间 | 申请驿站（免费 3–7 天）或住青旅 | **有面试通知才批驿站** |

**没有面试通知就过去，等于每天烧 80–150 元青旅钱等一个不确定的面试。** 一周就上千，而这笔钱本可以省下。

**可以问 HR 的两件事**：终面能否报销交通住宿（部分公司有）、能否安排线上终面。这两句问了不吃亏。

## 七、判停

| 信号 | 我这边怎么做 |
|---|---|
| 看 5 套无合适 | **放宽一项约束**（预算 +200 / 通勤 +15 分钟 / 接受合租），不是继续看第 6 套 |
| 预算内 0 套 | 预算与片区不匹配。改片区，或改预算，二选一 |
| 看 3 套都存在同样问题（如都朝北、都临街） | 说明片区选错了，换片区而不是换房源 |
| 中介反复推"另一套" | 停止沟通，换渠道 |
| 要求先交意向金/看房费 | 拒绝，直接结束 |
| 已看 10 套仍犹豫 | 不是你挑剔，是预算不够。回到预算恒等式重算 |

## 八、与主流程的接口

| 模块 | 本模块提供什么 |
|---|---|
| M5 城市 | 该城的**落脚三层方案**（驿站/青旅/长租），用于判断"能不能先过去再找" |
| M8 落脚 | 具体房源清单、通勤核算、真实月成本、合同核对 |

**M5 只出方案，M8 才出房源。** 城市没定时找房，等于给一个还不知道在哪上班的人租房。

## 九、合规与安全

- 不绕过平台验证与登录墙
- 不代替用户签约，不出具法律意见
- 押金、转账一律走合同主体，不打给"房东的朋友"
- 首次看房尽量白天、结伴，告知他人行程
