# 非对口就业对照表生成工作表

> 用于**不在** `03-direction.md` 那 20 个专业之列的专业。
> 输出必须是同样五列，否则无法与已有表对齐。

---

## Step 1 拆对口岗位池

| 项 | 记录 |
|---|---|
| 专业名 | |
| 检索关键词 | 「__ + 招聘」 |
| 同城岗位数 | |
| 学历要求分布 | 专科 __% / 本科 __% / 硕士 __% |
| 是否要求执业资格 | 是：__ / 否 |
| 岗位集中的城市 | |

## Step 2 判断窄在哪（命中 2 条以上为窄）

| 判断 | 命中 | 证据 |
|---|---|---|
| 数量窄：岗位 < 10 条 | ☐ | |
| 学历窄：多数要求硕士 | ☐ | |
| 资格窄：必须持证 | ☐ | |
| 地域窄：只在 1–2 个城市 | ☐ | |

**结论**：宽口径 / 窄口径（窄在哪：__）

## Step 3 可迁移能力（只用动词）

| 来源 | 能力（动词） | 具体例子 |
|---|---|---|
| 课程 | | |
| 实训/项目 | | |
| 实习 | | |
| 日常/爱好 | | |

**筛选**：每条必须能举出一个具体例子，举不出的删掉。保留 3–5 条。

## Step 4 相邻岗位（三种邻近，各至少 1 个）

| 邻近类型 | 岗位 | 为什么邻近 |
|---|---|---|
| 能力邻近 | | 同样需要 __ 能力 |
| 行业邻近 | | 同样在 __ 行业 |
| 场景邻近 | | 同样处理 __ 场景 |

**候选合计 3–5 个。**

## Step 5 最短缺口（只选一个）

| 缺口类型 | 补齐周期 | 是否短期可完成 | 选定 |
|---|---|---|---|
| 作品集 | 数周 | ☐ | ☐ |
| 行业知识 | 数周 | ☐ | ☐ |
| 证书 | 3–12 个月 | ☐ | ☐ |
| 销售能力 | 无法速成 | ☐ | ☐ |

---

## 输出（五列，必须填满）

| 专业 | 对口为什么窄 | 可迁移能力 | 相邻岗位（低门槛可进） | 最短缺口 | 适合信号 |
|---|---|---|---|---|---|
| | | | | | |

**自检**：

- [ ] "对口为什么窄"写了具体原因，不是"就业难"
- [ ] 可迁移能力是动词，不是名词
- [ ] 相邻岗位是具体岗位名，能搜出 JD
- [ ] 最短缺口只有一个，且短期内能补
- [ ] 适合信号能帮人做"我适不适合"的判断
