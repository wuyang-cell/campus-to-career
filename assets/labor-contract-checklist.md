## 试用期法定参考

| 合同期限 | 试用期上限 |
|---|---|
| 不满 3 个月 / 以完成一定工作任务为期限 | 不得约定 |
| 3 个月以上不满 1 年 | ≤ 1 个月 |
| 1 年以上不满 3 年 | ≤ 2 个月 |
| 3 年以上 / 无固定期限 | ≤ 6 个月 |

**试用期工资**：不低于本单位同岗位最低档工资或合同约定工资的 80%，且不低于当地最低工资。

## 风险信号

| 信号 | 处理 |
|---|---|
| 试用期不缴社保 | 书面询问 HR，保留记录 |
| 试用期超过法定上限 | 要求书面说明 |
| 合同主体与面试公司不一致 | 问清是外包还是主体变更 |
| 要求先交培训费/押金/服装费 | 拒绝 |
| 要求签"自愿放弃社保" | 拒绝，保留证据 |

## 出现争议

保留合同、聊天记录、工资流水 → 咨询当地人社部门、劳动监察或律师。
