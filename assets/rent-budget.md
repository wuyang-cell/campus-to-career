## 三、通勤权衡

| 项 | 数值 |
|---|---|
| 时薪 = 税后月薪 ÷ (21.75 × 8) | |
| 方案 A：租金 / 单程分钟 | |
| 方案 B：租金 / 单程分钟 | |
| 月多耗小时 = (B − A) × 2 × 22 ÷ 60 | |
| 租金差额 ÷ 月多耗小时 | |
| 判断 | 大于时薪 → 不值得 |
