## 三、断点诊断

| 现象 | 说明什么 | 通常有效（不是必须） |
|---|---|---|
| 投递多、沟通 0 | 第一层：进不了初筛 | 改关键词、地域表述、意向聚焦 |
| 有沟通、面试 0 | 第二层：沟通被刷 | 查到岗时间、薪资预期、话术 |
| 有面试、offer 0 | 第三层：面试或匹配 | 进面试那节 |
| 短期内大量投递、0 面试邀请 | 简历有结构问题，不是措辞问题 | 先改结构；继续投同一份，等于继续烧样本 |
